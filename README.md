# whiteboard-drawer

A modular C++-powered CNC whiteboard plotter designed to run standalone on a 
Raspberry Pi. The system uses a CoreXY kinematics architecture, an interactive 
state machine control loop, and dynamic binary matrix traversal to draw unique 
patterns.
